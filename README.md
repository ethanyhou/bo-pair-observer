# 配对观察

独立复现 Bo 视频中的 VTV／QQQ、CGDV／QQQ 30／35 日配对曲线。

网址：https://ethanyhou.github.io/bo-pair-observer/

页面提供曲线筛选、QQQ 价格背景、Risk On／Risk Off 日期与操作解释、区间切换及离线保存。

新增十年美债收益率分解面板，复算 Bo 2026-10-04 视频的四项分解及合成名义收益率，提供独立区间、五条曲线筛选、悬停／触摸和月份选择、各项读数及美股潜在利好／风险说明。

## 行情更新

GitHub Actions 在每个周一至周五美东 16:37 更新、18:17 补查，时区设置随纽约夏令时切换。GitHub 定时任务可能延迟；页面打开时及每 5 分钟检查最新发布的数据。手动点击“检查更新”读取已发布快照。

需要主动抓取新行情时，在仓库的 Actions 页面选择 **Update prices and deploy Pages → Run workflow**。

仅使用已经收盘的完整日线，含拆股调整，不做分红复权；当天行情在常规收盘 15 分钟后才纳入。三个标的采用共同有效截止日。Yahoo 接口失败时重试；持续失败时保留之前的数据并在页面显示警告。超过 5 个日历日的旧行情暂停操作参考。

下载的数据和最近一次抓取状态会由 Actions 提交回仓库，避免失败时丢失有效快照。这里没有实时盘中报价服务。

## 美债月度模型

数据来自[克利夫兰联储的 Inflation Expectations 官方表格](https://www.clevelandfed.org/indicators-and-data/inflation-expectations)，与 Bo 图中 FRED 的底层来源相同。Actions 每次运行同时检查模型更新；模型自身按月发布，网页仍读取已发布快照。官方发布日、预计下次更新日、模型月份单独显示；抓取失败保留 `src/bond_snapshot.json` 并显示警告。

公式：实际利率预期 = 十年实际利率 − 实际利率风险溢价；合成名义收益率 = 实际利率预期 + 通胀预期 + 实际利率风险溢价 + 通胀风险溢价。表格的实际利率页使用小数、风险溢价页使用百分比；构建时统一为百分比并验证四项之和。

默认展示 2026 年 4 月起的区间，与[视频 5:17 的图](https://www.youtube.com/watch?v=wERSMycMUNA&t=317s)同口径；历史数据修订可能造成小幅差异。黄色合成线看右轴，其余四项看左轴。独立缩放下，曲线交叉不构成信号。

图下的一句话结论随官方数据与比较范围自动更新：默认比较图中首尾月份，切换「所选月环比」后比较所选月份与相邻前月，并随悬停／触摸或月份选择更新。隐藏曲线只影响显示，结论始终使用全部四项；保存离线页面时保留当前比较方式。

每次打开、浏览器返回或切回页面时，查看月份恢复到最新已发布模型，并检查云端更新。鼠标悬停仅临时预览读数和月度结论，移开后恢复正式选择；点击／触摸图表或月份选择器才选定历史月份。静止鼠标因页面滚动或布局变化触发的事件不会改变月份。日线历史对照窗口在重新进入页面时也恢复到包含最新收盘数据的区间。

`src/bond_reading.js` 将 Bo 的定性解释实现为透明规则：将通胀预期与通胀风险溢价合并，比较实际利率预期、通胀因素和实际利率风险溢价的同方向贡献，增量／降幅最大表示贡献最大，并列时保留混合判断；实际利率预期下跌快于通胀因素时提示增长风险。比较按两位小数精度，缺少相邻月份时不把跨月变化当作环比。起止差异不代表期间每个月走势一致。

这些归纳不是 Bo 的原版程序或逐字发言，没有估计股票收益率或涨跌概率。月度模型不参与上方 30／35 日机械判断，也不改变仓位示例。

## 本地构建

Python 3.9 或更新版本，无第三方依赖：

```sh
python3 build_site.py --offline
python3 -m http.server 8000 --directory dist
```

主动抓取并构建：`python3 build_site.py`。允许失败时使用之前的数据：`python3 build_site.py --allow-cached`。

`src/` 是完整源码；`src/evidence/video_observations.json` 保存可读画面值与日期的观察记录。`dist/` 为生成的网站，不纳入版本控制。

债市数据解析校验：`python3 -m unittest discover -s tests`。动态结论与比较范围校验（Node.js 18 或更新版本）：`node --test tests/test_bond_reading.cjs`。

## 指标解释

默认公式为防御资产／QQQ 价格比的 30 或 35 个交易日 ROC；确认规则为连续两日同侧且当日继续同向，状态改变时标记一次。Risk On 为负向确认，Risk Off 为正向确认。过滤规则是独立复现推断，有限样本核对不能证明源码完全相同。

仓位示例和 QQQ／TQQQ／BOXX 的操作解释是依据公开视频做出的改写，页面注明来源与适用范围；它不是 Bo 公布的固定三基金交易系统，没有连接券商或下单。
